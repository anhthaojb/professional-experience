# Healthcare BI Dashboard

## Overview

A Business Intelligence dashboard developed for a public healthcare organization to support monitoring and analysis of operational data.

Due to confidentiality, proprietary datasets and internal business information are not included.

---

## My Role

**Data Analyst / BI Intern**

- Dashboard development
- KPI visualization
- Business requirement analysis
- Dashboard testing
- Demo preparation

---

## Key Responsibilities

### Dashboard Development

- Built and customized dashboard layouts.
- Created and configured charts and KPI visualizations.
- Added filters and adjusted dashboard structures based on requirements.

### Business Analysis

- Reviewed dashboard logic against business requirements.
- Identified visualization and business workflow issues.
- Refined dashboard structure based on feedback.

### Testing & Demonstration

- Tested dashboard functionality.
- Prepared demo flows and supporting documentation.
- Documented issues and follow-up items.
