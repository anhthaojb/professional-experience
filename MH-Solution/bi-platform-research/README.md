# BI Platform Research & Evaluation

## Overview

A research project focused on evaluating BI and data visualization platforms to support BI product development and client requirements.

The research covered visualization capabilities, dashboard features, chart types, and potential features that could be considered for BI products.

---

## My Role

**Data Analyst / BI Intern**

I was responsible for researching BI platforms, evaluating visualization capabilities, organizing findings, and documenting potential features and chart ideas.

---

## Research Areas

### BI Platform Features

* Dashboard capabilities
* Visualization features

* Dashboard interaction
* Customization capabilities
* Alerting-related features

### Data Visualization

* KPI visualization
* Bar charts
* Pie charts
* Progress charts
* Other analytical visualizations
